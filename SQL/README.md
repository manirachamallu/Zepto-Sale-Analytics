SQL Analysis

Overview

This folder contains the SQL analysis performed for the Zepto Sales Analysis project.

All queries were executed using Google BigQuery against four primary tables:

* Zepto_Orders
* Zepto_Products
* Zepto_Customers
* Zepto_Inventory

Analysis Areas

The SQL analysis covers:

* Data quality and validation
* Customer and order relationships
* Product and order relationships
* Inventory analysis
* Overall business KPIs
* City and category performance
* Product performance
* Customer loyalty and segmentation
* Monthly sales trends
* Delivery SLA performance
* Discount effectiveness
* Inventory versus sales
* Product opportunity analysis

Files

Zepto_Sales_Analysis.sql

Contains the complete SQL queries used for the analysis.

Zepto_Schema.csv

Contains the schema information for the four tables used in the project, including column names, data types, and nullability.

outputs/

Contains the CSV outputs generated by executing selected analytical queries in Google BigQuery.
